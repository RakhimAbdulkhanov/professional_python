## Стан проєкту

Початкова структура для лабораторної роботи №1.
Код розташований у `src/student_manager/`, автоматичні перевірки - у `tests/`.

## Встановлення

Потрібен Python 3.11 або новіший. Зовнішніх бібліотек для запуску немає.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
```

Linux/macOS: для активації використовуйте `source .venv/bin/activate`.
